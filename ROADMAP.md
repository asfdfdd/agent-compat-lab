# Roadmap

## v0.2

- OpenCode adapter.
- Capability-level executable probes and fixture projects.
- `--cwd` support for probing another repository.

## v0.3

- MCP configuration compatibility.
- Custom-agent/subagent definitions.
- Hook lifecycle comparison.
- Version-scoped evidence and deprecation metadata.
- Signed JSON snapshots of the public registry.

## Later

- Cross-platform CI runners that execute vendor CLIs in non-authenticated probe mode.
- A generated compatibility website backed by the same registry.
- A stable schema for third-party agent adapters.
- Historical diffs that show when a vendor capability changed.
